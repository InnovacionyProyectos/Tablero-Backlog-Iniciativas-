Mientras trabajas, los datos se guardan automáticamente en este navegador (almacenamiento local); no se comparten entre dispositivos ni personas. Usa Exportar Excel para guardar un .xlsx con todo el backlog y el historial de seguimiento en tu equipo (útil como respaldo o para subirlo junto al tablero), y Importar Excel para cargar un archivo exportado previamente. Haz clic en el nombre de una iniciativa para ver el detalle antes/después y el cálculo aplicado. "Entregado" se deriva del estado (Entregada). Las iniciativas marcadas como Trasladado o Discontinuado muestran su cálculo pero no se suman en los KPI de ahorro, para no confundir redistribución de trabajo con ahorro real.

Webhook a GitHub Actions

El token queda guardado solo en este navegador (no se sube al repositorio), pero cualquiera que use este equipo con esta página abierta podría verlo. Usa un token de acceso fino (fine-grained) limitado únicamente a este repositorio y con expiración corta, y no lo configures si esta página va a ser pública.
Debe coincidir con el "types" del repository_dispatch en tu workflow de GitHub Actions.
